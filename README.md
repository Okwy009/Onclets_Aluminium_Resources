# Onclet's Aluminum Resources

Website for Onclet's Aluminum Resources Ltd (RC: 880876), Eleko Junction, Ibeju-Lekki, Lagos.

- `index.html` is the whole site (one page, no build step).
- `images/` holds the gallery photos, resized for the web.

## Publish with GitHub Pages

Repo **Settings → Pages → Source: Deploy from a branch → Branch: `main` / root**. The site goes live at `https://<your-username>.github.io/<repo-name>/`.

## Add more photos

Put the new `.jpg` in `images/`, then copy one of the `<figure class="ph" ...>` blocks in the Gallery section of `index.html` and change the file name, caption and category (`windows`, `doors`, `glass`, `stock` or `workshop`).
